**July 3, 2026**

## New features

* **SERV Tools.** Enable server-side features by declaring specially named tools in any request — no SERV-specific API required. SERV detects tools prefixed with `serv_`, activates the feature, and strips the tool before the model runs. Works identically across the OpenAI SDK, Anthropic SDK, Vercel AI SDK, and raw HTTP. [Read the reference →](https://docs.openserv.ai/serv-reasoning/tools.md)
* **`serv_prompt_guard`.** Opt-in protection against prompt-injection attacks that try to leak or override your system prompt. Declare the tool by name to enable it — no parameters needed. [See usage →](https://docs.openserv.ai/serv-reasoning/tools.md#serv_prompt_guard)
* **`serv_shadow_agent`.** Runs a validate-and-iterate loop over the model's output to raise accuracy on hard tasks. Configure `hint` and `max_iterations` through schema defaults. [See usage →](https://docs.openserv.ai/serv-reasoning/tools.md#serv_shadow_agent)
