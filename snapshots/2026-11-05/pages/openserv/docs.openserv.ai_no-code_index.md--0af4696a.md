## Quickstart (No Code)

Follow these steps to get productive quickly:

1. Create your first Workflow — see [Workflows](https://docs.openserv.ai/no-code/workflows.md)
2. Add or build an Agent — see [Agents](https://docs.openserv.ai/no-code/agents.md)
3. Connect integrations/MCPs and manage [Secrets](https://docs.openserv.ai/no-code/connect/secrets.md) — see [Connect](https://docs.openserv.ai/no-code/connect.md)
